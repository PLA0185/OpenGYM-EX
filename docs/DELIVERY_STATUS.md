# OpenGym EX 2.0.9 当前交付状态

2026-10-01。名称暂用OpenGym EX；当前范围以[V12任务书](OpenGymEX_2.0_V12_双端任务书与验收清单.md)为准，[换机说明](新电脑接手说明与后续任务书.md)记录恢复步骤。V11及此前文档留作历史。

## 本轮完成

- 博主计划已转为本机执行方案：Bruce9张原始表、烧毁一切就是美教学动作的3套应用编排，真实ID映射、组次/休息/个人负重预填、缺失变式明确替代。共12位作者28项入口，其他16项为公开摘要的个人适配参考，不冒充完整原课。
- 选择具体计划后一次点击生成个人训练和七天饮食，传入选中原表、替代说明、官方要点和个人条件；候选优先参考动作但仍尊重器材和避练限制。修复AI格式解析丢exerciseId；未知ID拒绝，重量不由模型伪造。来源及边界见[博主计划说明](CREATOR_PROGRAMS.md)。
- 原进阶表与个人恢复规则冲突时提示原因并要求编辑/个人适配；源数字保留在原文记录，缺基线只提供试练重量，不冒充达到作者百分比负荷。


- 统一AI提示词先分析内置来源摘要/适用范围/恢复规则，再结合原话与档案；生成再提供相关真实预设参数实例。界面可查看输入知识来源及AI声明引用，未知来源ID拒绝，不宣称模型逐本阅读全文。
- 计划库按来源→类型→具体方案进入，四项组合筛选目标、强度、最长训练日预计时长与部位。普通正文防孤字（包含单字加标点），复制文本不插入隐形字符；营养说明全宽分行，底部应用按钮可达。
- 日期卡使用原生滚动、结束后更新索引，高度变化不强制跳位；实际便携包验证往右触摸滑回连续。320/360/412宽度与放大文字检查通过。
- 每周五次不机械填周一到周五；循环周核对主要肌群恢复/高努力间隔与新手力量次数，支持轻活动穿插。增加天数不覆盖明确可用星期，禁止轻活动时保留并提示复核；同ID现成方案不能绕过限制过滤。
- 菜单及本地替代优先同日不同菜、跨日不同组合；默认每菜三次是可行性不足时可放宽的偏好，用户明示的重复/预算/忌口仍是硬约束。改餐食不把弹性星期变为固定星期。

### 保留的既有功能

- 74套知识关联计划，按来源/类型/计划三级进入并支持搜索。覆盖五份中国资料、ACSM力量/增肌/爆发力、CDC有氧/抗阻和六种MET参考；33个指南活动都有入口。原文原则与应用星期/动作编排分别说明，传统/专项活动为计时入口，没有编造教学动画。
- 所有常规成人预设审核页的重量字段直接预填数字：个人记录优先，缺少基线时为明确标注的轻负重试练建议；自重0。百分比缺基线不冒充对应公斤。需要同伴辅助的动作不再进入普通候选或模板。
- AI及联合方案的训练、饮食独立分页，每页日期卡左右切换，各自保留日期，卡片按当前内容收缩。可直接打开食材/完整做法、编辑动作和换餐。
- 使用中国官方来源BMR/PAL及目标营养策略，分别处理减脂、增肌和维持；没有快速/正常减脂分类。自然语言更快需求仅在适用边界内调整。
- 改体重/目标/未来训练/餐食后统一核对平衡，保留刚改餐与实际历史，调整其余可用餐食并立即通知；小差异保留，不能满足时明示待复核。手动专业目标保留，不重复叠加整次运动或手环热量。
- 拍照/相册+分量描述+日期/餐次，视觉识别后本地计算营养估算区间并自动记录实际；明确选择是否替换该餐计划。照片不进入普通备份，取消/重复操作不重复记录。
- 修复计划份数编辑误计为实际摄入；待审核方案修改后联动核对并保存。保留402道完整食材/做法、逐步做菜与采购逐项勾选，以及已有短追问、手势返回、密钥粘贴和心率接入。

用户已反馈此前手机基本可用、心率广播正常。本阶段没有使用用户真实Key代测；新增相机/视觉账号和本轮安卓交互还需安装新版实际复测。
